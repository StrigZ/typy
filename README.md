# deb-python-gtk4-template

## Начало работы

Это простое GTK4 приложение на Python с поддержкой консольного запуска. После его установки программу можно запускать как через ярлык в меню "Все приложения", так и через терминал:
```
$ uncom-app-template -h
```
Выведет помощь по использованию в терминале. Для запуска в графическом режиме надо передать параметр `-g`.

При работе с проектом в качестве основы, важно заменить следующие умопинания имени шаблоны на новое имя программы:
* `/usr/bin/заменить_на_новое_имя` - заменить название скрипты, который вызывается (внутри заменить путь на вызываемый скрипт, смотри строчку ниже)
* `usr/lib/uncom/заменить_на_новое_имя/заменить_на_новое_имя.py`- заменить директорию и сам скрипт (внутри скрипта заменить APP_ID программы, пути к файлам и другие упоминания шаблона)
* `usr/share/icons/hicolor/_x_/apps/заменить_на_новое_имя.png` - заменить все иконки всех размеров
* `usr/share/uncom/заменить_на_новое_имя` - заменить название директории с дополнительными файлами программы
* `/debian/rules` - заменить название пакета в правилах сборки

По итогу замены нигде не должно остаться упоминания `uncom-app-template` - ни в именах файлов/директорий, ни внутри самих файлов.

## Настройка окружения

Для сборки надо установить следующие пакеты в систему:
```
sudo apt install dpkg debconf debhelper lintian devscripts
```

## Сборка .deb пакета

Для сборки нужно в корне проекта выполнить:
```
debuild -b -uc -us
```
Итоговый файл появится на уровень выше в родительской директории.
Важно! Во время сборки в папке debian генерируются временные файлы, которые не удаляются. Их не надо коммитить в репозиторий.

## Сборка текстов локализации

В коде в Python скрипте все тексты, которые обрамлены такой функцией `_("Text for translate")` будут собираться в файл. При изменении английского текста связка с переводом пропадет, тут надо быть аккуратным.

Примеры команд для работы с текстами локализации:
```
# Создание PO файла (в него надо вставить руками переводы всех строчек)
pygettext3 -d base -o ru.po usr/lib/uncom/uncom-app-template/uncom-app-template.py

Локализация из po файла в mo файл собирается автоматически при сборке пакета, но если надо собрать вручную, то вот команды для этого
msgfmt po/ru.po --output-file usr/share/locale/ru/LC_MESSAGES/uncom-app-template.mo
```
